# vlingo · 微邻国

**一个意思，八种语言，一起学。**

[🌐 在线体验](https://vlingo-study.vlynnhow.workers.dev/) · [📱 安卓安装包（发布中）](https://github.com/vlynnnn/vlingo/releases)

</div>

## 为什么做 vlingo？

我在使用 **Duolingo（多邻国）** 学习外语时，发现它的课程主要围绕单种语言展开：想比较同一个意思在多种语言里分别怎么表达，通常需要切换不同课程，没办法把它们放到一起学。

于是有了 **vlingo（微邻国）**：从一个中文意思出发，把对应的**八种语言表达和文字读音并排展示**，希望让不同语言之间的联系更直观。它不是多邻国的替代品，而是对多语言对照学习的一次尝试。

> 本项目与 Duolingo（多邻国）没有官方关联，也未经其认可或赞助。

## 目前支持

- **八种语言**：英语、日语、法语、俄语、德语、西班牙语、粤语、现代希腊语。
- **3000 个中文学习概念，34 个生活与旅行主题**，包含单词、短语和实用句。
- 按主题浏览全部词条、学习词卡、词典搜索、简单测验、收藏与错题复习。
- 可查看并撤销“已学会”标记。
- 展示文字读音参考（IPA、假名、罗马字、粤拼等）；学习记录主要保存在本机，可手动备份。

## ⚠️ Vibe Coding 与准确性声明

**这是一个 Vibe Coding（AI 辅助编程）实验项目。** 界面、功能和多语言词库的制作使用了 AI 辅助，主要出于个人兴趣，**不是经过语言教师或母语者逐条审校的正式学习教材**。

特别提醒：

1. **翻译可能有错。** 同一个中文词语在不同语境、地区可能存在多种译法，现有内容可能不自然、不完整或不准确。
2. **文字读音可能有错。** 包括 IPA、日语假名和罗马字、俄语重音／转写、粤语粤拼、希腊语转写等，部分读音由程序自动生成。
3. **没有语音功能。** 目前不支持播放真人或合成发音，也不支持跟读纠音；仅提供文字读音参考。
4. **进度没有跨设备自动同步。** 清除浏览器数据、卸载应用或更换设备前，请手动备份。
5. 中国大陆访问 Cloudflare 网页可能不稳定；安卓安装包以离线学习为目标。

发现翻译、读音或软件问题，欢迎通过本仓库的 Issues 提交具体词条和建议。**重要交流、专业翻译或考试请勿以本词库作为唯一依据。**
